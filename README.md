# Portal · Constitución en un Día · eConta Magnus

Generado y publicado automáticamente desde el panel (Configuración › Publicación) o desde la planilla (menú 🏛️ Constitución › 🌐 Publicar portal). No edites estos archivos a mano: se reemplazan en cada publicación.

- `index.html`, `_headers`, `404.html`: el portal (Cloudflare Pages).
- `portal.js` + `wrangler.jsonc`: el mismo portal como Worker (Cloudflare Workers Builds, si conectas el Worker a este repositorio).
